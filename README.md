# Viswanath Lab exploratory analyses

An academic-data-first interactive demo prepared by Cathy Liu for the UCSF Viswanath Lab. It parses 77 public Varian PRESS acquisitions from the Dryad dataset associated with Radoul et al. (2021), then stress-tests the paper's early 2-HG, glutamate, and GLX response signature across three glioma models.

Live demo: <https://liuzhitong330.github.io/viswanath-lab-demo/>

This is an exploratory review and decision-support tool, not a validated metabolite-fitting pipeline or a new experimental result. Data provenance and analytical limitations are documented in the demo.
